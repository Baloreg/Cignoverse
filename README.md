# Cignoverse Hub

L'hub ufficiale della community del Club del Cigno.

## Progetti
- **EcoCigno**: Sensibilizzazione sulla raccolta differenziata e calendario personalizzabile.
- **CignoLauncher**: Launcher di Minecraft moderno e multi-instanza.
- **Cignuroid**: App di emulazione di retro console.

## Dominio Custom
Configurato per `cignoverse.it`.
